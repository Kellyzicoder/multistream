How to connect OBS
  1. In OBS open Settings → Stream.
  2. Set Service to Custom.
  3. Paste the RTMP URL into Server and the Stream key above.
  4. Click Start Streaming in OBS.
  5. On Facebook and Instagram, press Go live on their page.
