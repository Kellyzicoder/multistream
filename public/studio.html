Where your video goes

Each channel gets the same picture and sound. Switch one off to stop sending to it. A channel that drops starts again by itself. Sign-in for YouTube and Facebook (titles, Go Live, chat) is in the Stream page under Settings.

Recording

Recordings are .mkv files, so they still play if the power goes out. VLC plays them.

Monitoring

Monitoring lets you hear an input in your headphones. Use headphones, or the microphone will pick up the speakers. Turn it on for each input in the Audio Mixer, under Tools.

Inputs

Add and set up sound inputs in the Audio Mixer: volume, mute, delay, low cut, bass/mid/treble, noise gate, compressor and limiter. "Computer sound" (what this PC plays) is in the Windows app.

Hotkeys

1 - 9Put that scene on air
Alt + 1 - 9Mute or unmute that sound input
RStart or stop recording
Shift + GStart or stop streaming (it asks before stopping)
FNext transition type
Arrow keysMove the selected item (Shift = 10 at a time)
DeleteRemove the selected item
Like OBS Studio (select an item in the Preview or the Sources list first)
Ctrl + FFit to screen (all of it, keeping its shape)
Ctrl + SStretch to screen
Ctrl + DCentre on the screen
Ctrl + RReset the transform (original size, no crop, no flip)
Ctrl + EEdit the item (properties)
Ctrl + C / Ctrl + VCopy the item / paste it into the scene you are editing
Ctrl + Z / Ctrl + Shift + ZUndo / redo a change to scenes and items (also Ctrl + Y)
Ctrl + ↑ / ↓Move the item in front of / behind the others
Ctrl + Home / EndMove the item to the very front / back
F2Rename the item
EscSelect nothing
F11Full screen for the Studio window
Ctrl + ,Open Settings

These work when the Studio is the window in front and you are not typing in a box. They cannot be changed yet.

1 to 9 put that scene on air

R start or stop recording

F next transition type
